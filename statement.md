# Problem Statement & Scope

## Problem Statement
Students and self-learners often lack lightweight, local tools to evaluate their domain knowledge, track learning progress over time, and analyze their quiz performance systematically.

## Scope of the Project
The Quiz Application provides a command-line interface (CLI) assessment tool. It manages interactive quiz modules, validates user inputs safely, logs quiz outcomes locally using JSON, and generates analytical summary reports.

## Target Users
- Students preparing for domain-specific examinations or self-assessments.
- Instructors seeking a lightweight utility to verify foundational knowledge.

## High-Level Features
1. **User Management Module**: Handles user profiles and persistent historical score logs.
2. **Quiz Engine Module**: Loads structured questions, processes user responses, and evaluates scores.
3. **Analytics Module**: Computes performance metrics including overall score averages and topic-wise statistics.
