

# Project Statement: Interactive Quiz Application

## Problem Statement

Students and self-learners alike find themselves in need of a straightforward method to practise fundamental computer science knowledge, verify understanding and track quiz scores. The lightweight local application allows users to take multiple-choice quizzes and analyze their performance.

## Scope of the Project
Python is used to create a command-line quiz application. Users will input their username, select a quiz topic, respond to questions and receive scores. Results are saved in local json file and can be assessed later via performance report.

The app has set questions on Python, Data Structures and General CS for interviewees. It does not come with browser UI, online accounts or question authoring tools.

## Target Users

- Learners aspiring to gain knowledge in introductory computer science. 
- Teachers who want a simple local tool for foundational knowledge checks.

## High-Level Features

- Username-based quiz sessions.
- Topic selection and multiple-choice questions.
- Input validation and immediate answer feedback.
- Score and percentage calculation.
- Local result storage in `results.json`.
- A report showing saved quiz results and the user's overall average percentage.
